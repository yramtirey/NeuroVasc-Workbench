# Changelog

## 0.1.0

First portfolio source release, prepared 2026-09-28.

- Cerebral vascular analysis pipeline with physical spacing and NIfTI affines.
- Named-vessel 3D visualization through FastAPI, React, TypeScript and VTK.js.
- Segmentation-derived caliber profiles and linked chart-to-3D point selection.
- Caliber, centerline and topology synthetic validation suites, each v1/v2.
- Actual isolated VMTK external-method benchmark and explicit unavailable Slicer CE status.
- Literature, method decisions, claim boundaries and TopCoW/IXI provenance.
- Curated public validation evidence; raw imaging and complete local archives excluded.

Lee skeletonization and EDT caliber remain production baselines. Advanced methods remain experimental. This is a research/engineering prototype, not diagnostic medical software.
