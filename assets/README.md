# Application screenshots

Only genuine captures of the running NeuroVasc UI may be placed here. No stock, AI-generated or reconstructed medical screenshots are used.

In these captures, the anatomy is an example annotated MRA segmentation from TopCoW's `MRA_IXI_HH` release, derived from IXI. Rendering, vessel highlighting and chart markers are produced by NeuroVasc; these are illustrations of software behavior, not clinical validation. Raw imaging and meshes are not distributed.

Attribution: TopCoW Challenge Organizers; original IXI Dataset, Brain Development, https://brain-development.org/ixi-dataset/. See [Data Sources](../DATA_SOURCES.md) for the TopCoW publication and official release.
