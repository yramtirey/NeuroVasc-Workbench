# Public-release provenance audit

Checked 2026-09-28. This audit concerns source attribution and release hygiene; it is not clinical validation.

## Real example identification

The official [TopCoW Training Data and External Testsets v1 record](https://zenodo.org/records/15692630) describes `MRA_IXI_HH` as 20 selected IXI HH MRA cases with TopCoW annotations. It explicitly identifies the original IXI CC BY-SA 3.0 terms and requests citation of TopCoW and the IXI source. The [IXI website](https://brain-development.org/ixi-dataset/) independently states the license and website-acknowledgment requirement.

The local downloaded `MRA_IXI_HH.zip` has MD5 **bb3339b460b639be4a0a4d6901443284**, matching the official archive checksum. MD5 is used here only to compare the published archive checksum, not as a security guarantee.

The compressed bytes of the working `cow_case_001_seg.nii.gz` have SHA-256 **7ee1bb10c9c08d5a653b91e8fd18790726e0bf9240ef96b3c578bd61ef9d00b6**. They exactly match:

```text
MRA_IXI_HH/cow_seg_labelsTr/IXI012-HH-1211-MRA_LPS_DFmasked_ROI-braincase_full_LPS_Mask.nii.gz
```

This establishes the annotated-file identity within the verified archive. No patient identity, clinical diagnosis or acquisition by NeuroVasc is implied. Raw images, segmentations, archives and real-case derivatives stay local.

## Citation and license decisions

The exact TopCoW citation used is: **Yang K, Musio F, Ma Y, et al. The TopCoW Challenge — Topology-Aware Circle of Willis Segmentation for CT and MR Angiography. NEJM AI. 2026;3(8). DOI 10.1056/AIdbp2500994.** The authors' [version-5 arXiv record](https://arxiv.org/abs/2312.17670v5) corroborates the journal reference, title, authors and DOI. The dataset's earlier preprint citation and the final publication are versions of the same work, not independent studies. Both version-specific bibliography records are retained.

The IXI attribution is: **“IXI data were obtained from the IXI Dataset, Brain Development: https://brain-development.org/ixi-dataset/.”** IXI is represented as a website in BibTeX, with no invented publication date or DOI. The TopCoW release has its own verified dataset DOI, **10.5281/zenodo.15692630**.

Original IXI data: **Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)**. NeuroVasc source code: **MIT**. MIT does not relicense the data. Genuine dataset-derived UI screenshots carry CC BY-SA 3.0 and explicit TopCoW/IXI attribution; rendering, selection and UI overlays are identified as modifications. See [Data Sources](../../DATA_SOURCES.md) and [image attribution](../../assets/README.md).

## Methods bibliography

The existing source-verification table in the [literature index](../literature/README.md) records primary publication/documentation links and access limitations. The release preserves the verified clDice, VMTK, WASID and tortuosity references. WASID has PMID/URL and no unverified DOI. The 2025 tortuosity review is identified as a review, not local validation. VMTK/Slicer documentation establishes method definitions, not NeuroVasc clinical performance.

The library now has 22 unique entries: the original 20 method sources plus the IXI website and TopCoW dataset record. Current documentation distinguishes the executed standalone VMTK benchmark from unavailable Slicer-based cross-sectional evaluation. Production Lee and EDT defaults are unchanged.

## Synthetic evidence and privacy

Analytic phantoms are generated by NeuroVasc; they are not TopCoW/IXI data. Curated CSVs and figures are byte-identical copies of local synthetic results. JSON summaries retain every numeric value; local and upstream build paths in diagnostic strings are generalized. [curation.json](../../validation/public_results/curation.json) records source/public hashes and transformations for 30 evidence files. Frozen hashes/affines allow public tests to verify all 76 original topology masks without distributing the masks.

The public candidate audit inspects Git index bytes, flags excluded data/build paths, credential patterns, private paths and files over 5 MB. This is a targeted release check, not a comprehensive penetration test or guarantee that every possible secret pattern is detectable. No raw data, credentials or private workstation paths were found in the reviewed candidate.
